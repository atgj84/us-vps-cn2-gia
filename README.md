## 500Mbps 端口和 500GB 流量，哪个会先卡住你

带宽是端口峰值，月额度看流量那一栏，这两个数经常被混着理解。

500Mbps 换算成下载速度约 62.5MB/s。500GB 流量如果是持续满载下载，跑完只要 2.3 小时左右。300Mbps 是约 37.5MB/s，跑完 500GB 大约 3.8 小时。所以别把 500Mbps 理解成"一个月能跑 500GB 的高速通道"，它只意味着某一瞬间的峰值够高，突发传输、拉镜像、传大文件时体验好。

摊到每天，500GB/月是 16.7GB，800GB/月是 26.7GB，1.2TB/月是 40GB。纯文字和小图站点，一天 16.7GB 很难用超；视频、文件下载、做转发代理，一周就能见底。

超出流量之后是限速还是暂停，官网公开页面没写。这条必须在购买前问清楚，尤其你打算跑下载或者多账号并发。

## 开通后的前 30 分钟

拿到 IP 和密码，第一件事是登录改密码。SSH 端口不一定是 22，开通邮件或面板里写的是哪个就用哪个，连不上先确认端口，别急着怀疑密码错了。

bash
ssh root@你的IP -p 邮件里的端口
passwd


进去之后按顺序做这几件：

bash
# Debian / Ubuntu
apt update && apt upgrade -y

# CentOS / AlmaLinux / Rocky
dnf update -y


装 fail2ban 挡 SSH 爆破：

bash
apt install fail2ban -y && systemctl enable --now fail2ban


改 SSH 端口并启用密钥登录。改 `/etc/ssh/sshd_config` 里的 `Port`，把 `PasswordAuthentication` 设成 `no`，重启 sshd 之前**先确认防火墙放行了新端口**，否则会把自己关在门外。用 UFW 的话：

bash
ufw allow 新端口/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable


再建一个普通用户，加 sudo 权限，日常用它登录，root 只留密钥通道。这半小时做完，后面能省掉很多糟心事。
